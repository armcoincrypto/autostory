Detailed first-campaign checklist (optional)
  1. Pick an account until it shows OK (Telegram session verified — not just a session file on disk).
  2. Select at least one sendable or joinable group — not invalid.
  3. Enter message text and Save settings (auto-join / join-request runs after save).
  4. Review Join results; fix targets that failed or wait for admin approval.
  5. Use Send test now before scaling to more accounts.
